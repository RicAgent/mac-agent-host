# Bring / check before the visit

- [ ] HDMI dummy plug (or any monitor/TV with HDMI cable to leave attached). Without a display the Mac Studio runs a low-res virtual screen and remote graphics work is sluggish.
- [ ] Ethernet cable from router to the Mac Studio (Wi-Fi works, cable is much better for remote screen).
- [ ] Both Macs on Apple Silicon and macOS 14+ (Sonoma or newer): needed for Screen Sharing "High Performance" mode. Check: Apple menu > About This Mac.
- [ ] Friend's admin password and Apple ID at hand. Decide FileVault (see README).
- [ ] Tailscale account: friend signs up with Google/Apple/GitHub (free personal plan).
- [ ] Claude account that will PAY for the agents (Pro or Max subscription; Max for long autonomous runs). Login happens from the Mac Studio terminal with a browser code.
- [ ] GitHub account for the agents (optional, only if they push code).
- [ ] Upload bandwidth at the Mac Studio's location: at least 20 Mbps up for fluid remote design work. Run a speed test on site.
- [ ] Phone hotspot on the MacBook Air to test "from outside" before leaving.
